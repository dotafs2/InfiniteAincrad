# Project map tour · 2026-09-22

One video tour of the repository's own maps, captured **by each scene's own capture switch**, rendered fully off-screen. No save is written and no provider is called: every scene used here reports `model_calls: 0` / `save_writes: 0` in its own evidence file, and the living quarter is opened through a **copy** of a saved world with `--town-restore` (read-only).

[map-tour.mp4](map-tour-20260922/map-tour.mp4) — 57.2 s, 1280 × 720, H.264 / yuv420p, 30 fps.

Each segment carries the map name and a one-line description burned in by ffmpeg; nothing was redrawn or faked.

## How it was captured

```powershell
python -X utf8 tools/capture_map_tour.py        # per-scene --capture-dir, window off-screen
python -X utf8 tools\build_map_tour_video.py     # stills -> captioned clips -> concat
```

Every capture run used `--position -2400,-1400 --resolution 1280x720`, so the window never appears on the desktop. The living quarter run copied `tmp/mvp-autonomy-20260914/prepared/real/canonical-world.json` into the capture directory, passed `--town-restore` (which the scene documents as never advancing the world), and additionally requested `--quarter-probe`, `--quarter-report=` and `--town-capture=`.

## Residents walking (offline physics probe)

The quarter segment is recorded from a read-only viewer camera 42 m above the market square while the scene runs its own physics walk probe:

```powershell
python -X utf8 tools/capture_map_frames.py --only quarter-walk-motion
# -> game/tests/map_capture.gd loads town_street.tscn with a COPY of
#    tmp/mvp-autonomy-20260914/prepared/real/canonical-world.json,
#    --town-restore (read-only) and --quarter-probe
```

The probe completed all three legs and reported every resident reaching its target; the leg lines are kept verbatim in [walk-probe-legs.json](map-tour-20260922/walk-probe-legs.json):

```
QUARTER_WALK_LEG enter_home   [{"leg":"enter_home","resident":"shared:gardener","reached":true,"seconds":2.93,...}]
QUARTER_WALK_LEG visit_market [{"leg":"visit_market","resident":"shared:innkeeper","reached":true,"seconds":6.42,...}]
QUARTER_WALK_LEG return_home  [... reached ...]
```

1560 frames were captured at 6 fps over 260 s of probe time, **986 of them distinct** (the earlier attempt failed because the scene's own camera was parked away from the walking routes and produced 283 identical frames). The 20-second clip is the first segment of the tour after the title card.
