# H110 — Common resident capabilities

The user requested a broad foundation for reusable, extensible and parallel behavior. This delivery adds one capability boundary, not a catalogue of fictional powers. Production resident turns, ordinary offline choices, the scene and maintenance/restore writers now use it. Existing rules are adapted; new modules compose behavior without growing the inheritance chain.

The [capability standard](../design/action-capability-standard.md) defines interfaces, resource enforcement, consent, lifecycle, persistence, privacy and extension checks. There are 33 registered contracts: 27 existing adapters and six new entry points for free speech, private observation and the joint-visit protocol. Current catalogue families cover life, movement, perception, knowledge, learning, social interaction, inventory, contracts, production and cooperation.

## Remaining scope

The active world `shared:restart-20260918-01` is still seq43, with the original 32 real model decisions and the same ledger. This engineering pass did not resume paid village life or establish voluntary adoption. Original seq450 and its GM records remain on the other computer.

The joint protocol currently covers two residents visiting a known place. It does not implement arbitrary shared production, generic multi-resident planning, synchronized arrival or cancellation of a running visit. Resource contracts document enforced reducer rules; they are not an automatic parallel lock scheduler. Farming, animal care, weaving, fishing, sustained iron/flour supply and evidence-backed relationship growth remain future capabilities. Existing navigation overlaps and earlier renderer issues remain separate work.

Continue with a separately bounded same-world observation, preserve every sequence/reply, and measure whether residents voluntarily use the new opportunities. Extend only the missing concrete mechanics through the common contracts; a GM's suggestion or a personality description is not proof of an implemented capability.
