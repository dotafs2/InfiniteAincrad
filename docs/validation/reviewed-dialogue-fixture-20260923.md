# Reviewed dialogue fixture adapter

`game/agents/reviewed_dialogue_fixture_adapter.gd` wraps the test-only alias adapter and the optional proposal review gate. `prepare()` accepts only the exact raw string, builds an independent review fixture from the current `view.available_actions` and offered alias map, and stores only the raw string, alias, canonical action ID, and public review fields after a structurally accepted, intent-compatible review. `authorize()` ignores editable prepared flags, revalidates the original raw string against the current context, requires the same alias-to-action binding, requires explicit caller authorization, and delegates the final bounded decision to the existing adapter.

The wrapper does not execute actions, grant authorization from intent compatibility, or verify semantic truth. Public review fields and the final decision exclude private thought. The internal prepared raw string intentionally retains the original envelope, including any private field, for revalidation; it is not a public transcript. Results retain `execution_authorized: false`; a successful wrapper result includes `decision_authorized: true` to indicate the caller authorized returning the existing fixture decision shape with `action` and caller reason. The world still checks and executes that decision separately.

The final 11-check suite covers consistent preparation, no caller authorization, malformed raw types, forged flags with mismatched intent, same-family canonical remapping, and removal of current targets or claim IDs. Parent verification used Mono and exited cleanly; logs are in `private/iteration-20260923/reviewed-adapter-parent/`.
