# Dialogue proposal review gate

`game/agents/dialogue_proposal_review.gd` is an optional offline review step that includes receipt parsing. It accepts the raw envelope string and an independently exported fixture containing `context` and exact `{alias, action_id}` options. It rejects duplicate or missing option mappings, requires the option aliases to equal `context.action_ids`, and never derives authorization context from the candidate.

`ok` means the review input was processed as a valid receipt/fixture pair; it is not an approval signal. Consumers must inspect `structural_accepted`, `review_required`, and `reason`. Every result keeps `execution_authorized: false`, including `intent_compatible` results.

Known canonical action families map conservatively to expected intent: `contract:accept:` to `agree`, `contract:reject:` to `refuse`, `contract:offer:` to `offer`, and `share-skill:` to `disclose`. Unknown families and empty `next_action` remain review-required. A valid declared intent only resolves the family intent mismatch; it does not assert semantic truth or execute the action. Every result reports `execution: "not_attempted"`, `execution_authorized: false`, and `semantic_truth_verification: false`; private thought is not returned. Compatible intent is reported as `intent_compatible`.

The acceptance suite passes 22 checks. It includes synthetic consistent accept/refuse/offer/disclose counterparts, intent mismatch, no action, unsupported alias, unmapped action, alias remapping, duplicate options, and malformed raw input. It also reads all three saved real outputs: they remain structurally valid but require review, with expected intents `disclose`, `agree`, and `refuse`. Source hashes stay unchanged.
