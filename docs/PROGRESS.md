## 离最小 MVP 还差四步

这是原路线图 M20 的近期验收顺序，不另建路线图。

| 步骤 | 要得到的可见结果 | 当前状态 |
| --- | --- | --- |
| 1 · 居民能应对受阻 | 走不到材料点时本人知道，能等待或取消；再次出发、重启不破坏记录 | 🟠 收尾复核，H24 / H26 |
| 2 · GM 能接到真实问题 | 运行证据、居民的缺失能力提议进入独立 GM 入口，重复问题去重 | ⚪ 尚未接通，M20H / M20D |
| 3 · GM 完成修复交付 | 十个 GM 各有会话与任务履历；认领→实现→测试→审核→更新同一世界 | ⚪ 开发工具路线已实跑，世界任务链未接通，M20D / M20E |
| 4 · 10+10 共同运行 | 十名真实 Kimi 居民与十个 DeepSeek GM 在同一正式档完成一次需求或问题闭环，并重启续接 | ⚪ 待真实联调，M20A / M20B / M20C / M20F |

**工程粗估：配置和正式世界来源就绪后，还需约 1–3 个工作日开发与联调。** 这是基于当前代码和这轮修复速度的估计，会按实际验收修订。完整首镇、全部美术、公开发行与长时间稳定性仍是后续方向，不作为首次共同运行的前置。

第一次 MVP 的结果要能复查：居民自主生活 → GM 从真实证据接到问题 → 做出经测试的改进 → 同档更新 → 居民实际感知或采用 → 重启后身份、财物、经历与未完承诺继续保留。不能只看进程数量。

## 这轮实际进展

- DeepSeek 通过原生工具会话自行读代码、实现、运行测试和修错；GPT-6 负责设计与独立复核。
- 离线受阻反馈已有五类实际场景共 **223 项**、状态专项 **206 项**的通过记录；NPC 付费调用为 0。
- 当前仍在修复合法长指令 ID、取消成功反馈，并补验 **32 条关闭历史与 10 个进行中任务并存**。这版候选尚未接受发布，H26 保持橙色。
- 截至 10:26（上海），215 个完整 DeepSeek 响应有用量回执，输入缓存命中约 **99.1%**；另 1 次网络中断的用量和费用保留为未知。用户已批准这次例外继续，原会话已恢复。
- 真实 Kimi 配置路径与正式世界来源待确认；原镇私有主档未在本机找到，现有测试档不会冒充原镇。
