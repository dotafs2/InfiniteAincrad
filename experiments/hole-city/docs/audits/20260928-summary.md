## Reproduction scope

City and food probes are retained under
`artifacts/reference-audit-20260928/{city,food}/`. The parent independently
reproduced UI state/progression with the retained `ui/probe.gd` and
`ui/probe.json`. The UI completion uses an explicit fixture score, not a human
playthrough. The food route uses existing autoplay, not measured human speed.

The parent also ran the existing portrait touch/animation suite: 30 checks
pass. That result does not cover collection touch interaction, NPC facing,
long-running rain, or real device rendering. No large regression or timing run
was repeated; no absolute timing was measured while agents ran concurrently.

All probes use --test and no player-save path. Runtime source and the deployed
v0.7.0 package remain unchanged, verified in the audit manifest. All owned
helpers exited. The existing preview server and user apps were left running.

## Current improvements that remain valid

Snack Garden is already a connected non-nine-grid map with 2,594 physical
objects, 136 buildings, 15 heaps, ten rain recipes and explicit rounded/glossy
food materials. Current scene acceptance covers individual objects and NPC
falls. The audit does not repeat obsolete claims that every NPC floats, every
pile is fused, or all food geometry lacks rounded edges. Final visual fidelity
still requires real captured game frames.
