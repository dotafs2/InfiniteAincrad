Calling the real `acceptance()` function returned success. `run()` rejects script/parse/export errors and two placement errors, but ignores other native `ERROR:` records. Runtime/resource failures should fail, with only exact documented environmental diagnostics allowed.

The guard should cover actual runtime scripts/scenes/assets/import configuration and export settings.

A later copy/checksum failure can leave a mixture of old and new files. A prepared directory plus backup/rollback is preferable to reporting an unchanged prior preview after any installation failure.
