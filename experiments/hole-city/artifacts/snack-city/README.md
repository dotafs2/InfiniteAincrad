# Snack City evidence

`final-validation.json` is the authoritative eight-suite, 191-assertion summary,
including file hashes for the final Web build and relevant source/assets.

- `export-acceptance.json`: 39 checks loading the final PCK, including all ten
  rain landings/collections, initial-size NPC swallowing and tower release.
- `export-rounds.json`: actual food-map rounds with rain and the final gameplay
  code; only the cosmetic result-screen badge changed after this round capture.
- `final-regressions.json`: the final source-level portrait, map, city-round,
  food-round and dedicated snack checks before the stricter awake-body cap.
- `regressions.json`: earlier checkpoint, including two obsolete test
  expectations subsequently updated for the new button text and protected tiers.
- `food-opening.json` and `food-grown.json`: final headless Mac frame traces,
  excluding GPU/device behavior. The grown trace includes one 29.723 ms outlier.

Browser visual review and iPhone 14 hardware acceptance are not claimed.
